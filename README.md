# My-Cloud-Share

Public File Sharing · 公开分享仓库

> 专门存放需要分享给他人的文件，任何人可通过链接访问。
> 私有文件请勿上传至此仓库。

---

## 📂 目录索引

| 目录 | 用途 |
| ---- | ---- |
| [Documents](./Documents) | 文档类分享（PDF、Word、Markdown 等） |
| [Images](./Images) | 图片分享 |
| [Software](./Software) | 软件、安装包分享 |
| [Other](./Other) | 其他类型文件 |

---

## 🔗 分享链接说明

文件上传后，有两种链接方式：

### 方式 1：文件页面链接（可预览）

```
https://github.com/wenrouhao/My-Cloud-Share/blob/main/Documents/文件名.pdf
```

### 方式 2：直接下载链接（Raw）

```
https://raw.githubusercontent.com/wenrouhao/My-Cloud-Share/main/Documents/文件名.pdf
```

> 💡 **建议**：PDF、TXT、配置文件等优先使用 Raw 直接下载链接。

## 📝 使用流程

1. **分享文件**：将文件上传到对应目录 → 复制 Raw 链接 → 发送给对方
2. **更新文件**：上传新版本替换旧文件，链接保持不变
3. **停止分享**：删除文件（注意：已被下载的副本无法收回）

---

## ⚠️ 注意事项

- 公开仓库的文件**任何人都能访问**，请勿上传私人信息
- 文件一旦分享，删除后无法收回已传播的副本
- 单文件不超过 25 MiB（网页上传）
